# NBA-Dashboard
NBA player data pulled from NBA.com and ESPN datasets using Python libraries (requests and pandas), cleaning and collated in Excel and visualized in Power BI to identify key performance indicators and historical performance trends.

Aim: to identify outlier players across multiple statistics to aid in personal fantasy game decisions.

Output: visuals comparing player statistics across multiple seasons to identify performance trends, and identifying key performance indicators that may not be immediately apparent through high level statistics.

Input: data collected from NBA.com and ESPN data sets using Python pandas and requests libraries. Data from NBA.com contains player-game data at row level. The entire data set contains all player stats for each game across seasons 2023-24 to current. ESPN data pulls give player related data like positions, current teams, current fantasy team in our league. 

Process: data is cleaned (since data is from separate source) and collated in Excel before being loaded into Power BI for visualization.
